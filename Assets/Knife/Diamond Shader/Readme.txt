Material Properties
Scale, Ref Plane - changes noise parallax scale
Noise Texture - noise pattern
Noise Color - maximum color of noise
Color Tiling - size of noise pattern
Color Front - main color of diamond and opacity
Alpha Fresnel Scale, Power - opacity by fresnel parameters
Fresnel Scale, Power - scale and power of white fresnel emission gradient
Inner Fresnel Scale, Power, Color - parameters of "inner" fresnel emission effect
Distortion - amount of distortion of the background
Smoothness, Metallic - PBR parameters of sufrace
MainTex - surface color texture
Speed - speed of noise pattern moving
Noise Emission Scale - size of noise gradient
Noise Emission Speed - speed of noise gradient
